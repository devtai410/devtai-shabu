# devtai · Shabu & Happiness

หน้าร้านชาบูภาษาไทยด้วย React 19, TypeScript, Vite, React Router และ Redux Toolkit รองรับมือถือ แท็บเล็ต และเดสก์ท็อป

รอบนี้เป็น UX/UI และการทำงานฝั่งเบราว์เซอร์ ใช้ mock data ทั้งหมด ไม่มี API, backend, ระบบสมาชิก หรือการชำระเงินจริง ชื่อร้าน สาขา ราคา คะแนน และโปรโมชันเป็นข้อมูลตัวอย่าง

## เปิดใช้งาน

ใช้ Node.js 22 แล้วรันจากโฟลเดอร์โปรเจกต์:

```powershell
npm ci
npm run dev -- --host 127.0.0.1 --port 5174
```

เปิด http://localhost:5174 ถ้าพอร์ตถูกใช้งานแล้ว ให้ใช้เซิร์ฟเวอร์เดิมหรือเลือกพอร์ตอื่น

```powershell
npm run build
npm run preview
```

คำสั่ง build ตรวจ TypeScript และสร้างไฟล์สำหรับเผยแพร่ใน `dist/` เมื่อขึ้นโฮสต์ภายหลังต้องตั้ง SPA fallback กลับไปที่ `index.html`

## GitHub และ Vercel

ใช้ GitHub Desktop เพิ่มโฟลเดอร์โปรเจกต์ด้วย **File → Add local repository** แล้วกด **Publish repository** เพื่ออัปโหลดซอร์สโค้ดขึ้น GitHub โดย `.gitignore` จะไม่รวม dependency, ไฟล์ build, ZIP, log และไฟล์ `.env`

ใน Vercel เลือก **Add New → Project** แล้ว import repository นี้ โดยใช้ค่าต่อไปนี้:

| การตั้งค่า | ค่า |
| --- | --- |
| Root Directory | โฟลเดอร์รากของ repository (`./`) |
| Framework Preset | Vite |
| Node.js | 22.x |
| Install Command | `npm ci` |
| Build Command | `npm run build` |
| Output Directory | `dist` |
| Environment Variables | ยังไม่ต้องตั้งค่า |

ไฟล์ `vercel.json` กำหนด build และ SPA rewrite ไว้แล้ว เพื่อให้เปิดหรือรีเฟรชหน้าย่อย เช่น `/shop`, `/checkout` และ `/dish-description/101` ได้โดยตรง หลังเผยแพร่ให้ตรวจหน้าแรก รูปอาหาร และการเปิดหน้าย่อยโดยตรงอีกครั้ง

อ้างอิง: [Vite บน Vercel](https://vercel.com/docs/frameworks/frontend/vite) และ [การกำหนดเวอร์ชัน Node.js](https://vercel.com/docs/functions/runtimes/node-js/node-js-versions)

## หน้าจอที่ทำไว้

| เส้นทาง                     | การใช้งาน                                  |
| --------------------------- | ------------------------------------------ |
| `/`                         | หน้าร้าน เมนูแนะนำ หมวดหมู่ และโปรโมชัน    |
| `/shop`                     | ค้นหาเมนู กรอง 8 หมวด และเรียงราคา         |
| `/shop?category=sets`       | ชุดชาบูสุดคุ้ม                             |
| `/dish-description/101`     | รายละเอียดเมนู ส่วนประกอบ และสารก่อภูมิแพ้ |
| `/favorite`                 | เมนูโปรด                                   |
| `/order`                    | ตะกร้า จำนวนอาหาร ส่วนลด และวิธีรับอาหาร   |
| `/checkout`                 | ฟอร์มสั่งซื้อจำลอง พร้อมตรวจข้อมูลจำเป็น   |
| `/checkout-success?order=…` | สรุปคำสั่งซื้อที่ทดลองบันทึก               |
| `/order-history`            | ประวัติคำสั่งซื้อในเบราว์เซอร์นี้          |
| `/reservation`              | ทดลองกรอกและบันทึกการจองโต๊ะ               |
| `/all-offers`               | โปรโมชันตัวอย่าง                           |
| `/profile`                  | ทางลัดบัญชีสำหรับผู้เยี่ยมชม               |

ไม่ต้องเข้าสู่ระบบ รายการโปรดและตะกร้าจำไว้ด้วย Redux Persist ประวัติคำสั่งซื้อและการจองตัวอย่างบันทึกใน localStorage จึงแยกกันตามเบราว์เซอร์ ไม่มีการส่งข้อมูลไปยังร้าน

## ข้อมูลและกติกาตัวอย่าง

- เมนู 12 รายการ แก้ไขชื่อ ราคา หมวดหมู่ และรายละเอียดที่ `src/data/mock.ts`
- ใช้โค้ด `DEVTAI10` ลดค่าอาหาร 10% เมื่อยอดอาหารอย่างน้อย ฿500 หากลดจำนวนอาหารจนยอดต่ำกว่าเกณฑ์ ระบบจะนำส่วนลดออก
- ค่าจัดส่ง ฿49 และส่งฟรีเมื่อยอดอาหารก่อนส่วนลดครบ ฿999
- รับที่หน้าร้านไม่มีค่าจัดส่ง
- ราคาอาหารแสดงเป็นเงินบาทและเป็นราคารวมภาษีตาม UI ตัวอย่าง
- ตัวเลือกเงินสดและพร้อมเพย์เป็นเพียง UI ไม่มีการเรียกเก็บเงิน สร้าง QR หรือเชื่อมระบบรับชำระ
- การจองตรวจวันเวลาในเขตเวลา Asia/Bangkok แต่ยังไม่ตรวจจำนวนโต๊ะว่างหรือแจ้งร้าน

## โครงสร้างสำหรับทำต่อ

- `src/components/shabu/` — โครงหน้าร้าน การ์ดอาหาร ไอคอน ตัวกรอง และสรุปตะกร้า
- `src/screens/` — หน้าจอที่ใช้งานใน routing ปัจจุบัน
- `src/hooks/useGetDish.tsx` และ `useGetDishes.tsx` — อ่านเมนูจาก mock data ในเครื่อง เปลี่ยนจุดนี้เมื่อเริ่มเชื่อม API
- `src/store/` — Redux สำหรับตะกร้าและรายการโปรดจากเทมเพลตเดิม
- `src/data/local.ts` — การเก็บคำสั่งซื้อจำลองและคำนวณค่าจัดส่งฝั่งหน้าเว็บ
- `src/css/shabu.css` — รูปแบบร้าน devtai และ responsive layout
- `public/images/` — ภาพชาบูและเมนูที่สร้างด้วย built-in imagegen ใช้ไฟล์ในโปรเจกต์ทั้งหมด
- `docs/image-prompts.md` — prompt เต็มและตำแหน่งไฟล์ภาพที่ใช้

นำหน้าจอ ส่วนประกอบ รูปภาพ ไอคอน ฟอนต์ และ dependency ของเทมเพลตเดิมที่ไม่ได้ใช้งานออกแล้ว เก็บเฉพาะส่วนที่หน้าร้านปัจจุบันเรียกใช้ พร้อมใบอนุญาตฟอนต์และเอกสารภาพประกอบ

## ไฟล์สำหรับส่งต่อ

`frontend.zip` มีซอร์สโค้ดหน้าบ้าน รูปภาพ ฟอนต์ ไฟล์ตั้งค่า และคู่มือ ไม่รวม `node_modules/`, `dist/`, ภาพตรวจงาน และ log เมื่อแตกไฟล์แล้วให้รัน `npm ci` ก่อนใช้งาน ส่วน `dist/` สร้างใหม่ได้ด้วย `npm run build`

## ตรวจสอบงาน

ผ่าน `npm run build` และตรวจบน Google Chrome แบบ headless: ค้นหา/กรอง/เรียงเมนู, เพิ่มลดจำนวน, ส่วนลดและเงื่อนไขขั้นต่ำ, ยอดจัดส่งและรับหน้าร้าน, validation, สั่งซื้อจำลองทั้งสองแบบ, ประวัติรายการ, รายการโปรดหลังรีเฟรช, จองโต๊ะ, เมนูที่ไม่มีอยู่ และ navigation บนมือถือ

ก่อนเก็บกวาดไฟล์ เคยตรวจการแสดงผล 9 หน้าที่ความกว้าง 320, 375, 390, 768, 1024 และ 1440 พิกเซล ไม่พบหน้าเว็บล้นแนวนอน และไม่พบ API request ภายนอกหรือ runtime error ระหว่างการทดสอบ ภาพตรวจงานและรายงานเก่าถูกนำออกจากชุดส่งต่อแล้ว
